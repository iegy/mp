## التحميل
من صفحة **[الإصدارات (Releases)](https://github.com/iegy/mp/releases/latest)**:

| الملف | لمين |
|---|---|
| `Cassette-…-arm64-v8a.apk` | أغلب الموبايلات والتابلت الحديثة (اختار ده لو مش متأكد) |
| `Cassette-…-armeabi-v7a.apk` | الأجهزة القديمة (32-بت) |

| `Cassette-…-universal.apk` | يشتغل على أي جهاز (حجمه أكبر) |
